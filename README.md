# web-assignment1

https://yerassell.github.io/web-assignment1/

This repository includes four folders representating four tasks. Each html file has a navigation bar that links to each others.

## Brief description
- Task 1 contains Personal Webpage. It consists main information and facts about me.
- Task 2 is a webpage about the movie Coraline. According to the assignmetn requirements, it consists of navigation bar, header, sidebar, main content and footer.
- Task 3 is a Tribute Page for Audrey Hepburn.
- Task 4 is related to Form and Table creation and styling. The page consists of form to fill information about yourself and table of students with their grades.

## Instructions
To run the project:
1. Clone this repository to your local device (if Git is downloaded in your device)
   ```bash
   git clone https://github.com/yerassell/web-assignment1.git
   ```
   If Git is not downloaded in your device, click the green button **Code** ath the right top of the repository, select **download ZIP**, unzip the downloaded file.
2. Open the project folder in your device
3. Open the html file inside any task folder. It will open and display the website on your default web browser. The navigation bar will guide you to other tasks.
